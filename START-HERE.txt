FINTEL SECURE 2.0 — START HERE

1) Open this folder in VS Code.
2) Make sure Node.js 18+ and MongoDB are installed/running.
3) Copy .env.example to .env and fill MONGODB_URI + JWT_SECRET.
4) If you want an admin account, set ADMIN_EMAIL, ADMIN_PASSWORD and ADMIN_NAME in .env.
5) Open Terminal #1:
   npm install
   npm run server
6) Open Terminal #2:
   npm run dev
7) Open the Vite URL (normally http://localhost:5174).

Important:
- Do NOT put your old .env into source control.
- The stock/IPO area is a research workspace. Paper Portfolio does not send real trades.
- The IPO board is reference/demo data; verify final terms/dates with the latest exchange/issuer notice.
